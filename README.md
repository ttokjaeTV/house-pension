# 주택연금 계산기 · 똑재TV

나이(부부 중 연소자)·집 시세·주택 유형으로 주택연금 월지급금을 계산하고, 가입 나이별로 "○세까지 받은 합계"를 비교하는 계산기.

- 사이트: https://ttokjaetv.github.io/house-pension/
- 데이터: 한국주택금융공사 [월지급금 예시](https://www.hf.go.kr/ko/sub03/sub03_01_01_02.do) — 종신지급방식 정액형, **2026.03.01. 기준**, 일반주택·노인복지주택·주거목적 오피스텔 3개 표(55·60·65·70·75·80세 × 1억~12억원, 천원/월). `src/hf_table.json`에 원 단위로 저장(2026-10-24 확인). 공사 예시 문구(70세·3억원: 92만 3천원 / 78만 9천원 / 74만 6천원)와 일치함을 시험으로 확인.
- 계산: 표 사이 나이·집값은 직선 보간, 1억원 미만은 비례, 55세 미만 가입 불가, 80세 초과·12억원 초과는 표 끝 값.
- **지급표는 보통 매년 3월에 바뀐다** → 공사 누리집 표로 `src/hf_table.json`을 갱신하고 `basis`·화면 기준일 문구를 바꾼 뒤 시험 기대값(70세·3억원)을 공사 예시 문구로 고친다.
- 넣지 않은 것: 공사 실제 산식과의 차이, 보증료·이자(대출 잔액에 쌓임), 정액형 외 지급 방식, 우대형.

## 수정하는 법
`src/`를 고친 뒤 `python src/build.py` → `index.html`. 시험 `node src/test.js`.
